# DISTORT — فروشگاه + پنل مدیریت

یک سرور بدون وابستگی (پایتون یا Node.js) که هم فروشگاه را سرو می‌کند و هم پنل مدیریت را.

## اجرا

دو سرور با یک رفتار و یک فایل داده وجود دارد؛ یکی را اجرا کنید:

**با پایتون** (نسخهٔ ۳٫۸ به بالا، بدون نصب هیچ بسته‌ای):

```bash
python server.py        # در ویندوز: py server.py
```

**یا با Node.js** (نسخهٔ ۱۸ به بالا):

```bash
node server.js
```

- فروشگاه: http://localhost:3000/
- پنل مدیریت: http://localhost:3000/admin/

بار اول، رمز عبور مدیر به‌صورت تصادفی ساخته و **در ترمینال چاپ می‌شود**. بعد از ورود، از تب «تنظیمات» عوضش کنید.
اگر رمز را فراموش کردید، فایل `data/admin.json` را پاک کنید و سرور را دوباره اجرا کنید.

سرور پایتون به‌صورت پیش‌فرض فقط روی همین کامپیوتر (`127.0.0.1`) در دسترس است. برای دیدن از گوشی یا کامپیوتر دیگر در همان شبکه: `HOST=0.0.0.0 python server.py`.
(در ویندوز: `set HOST=0.0.0.0` و بعد `py server.py`.)

## متغیرهای محیطی

| متغیر | کار |
|---|---|
| `PORT` | پورت (پیش‌فرض ۳۰۰۰) |
| `HOST` | آدرس شنود (پیش‌فرض: پایتون `127.0.0.1`، Node `0.0.0.0`) |
| `ADMIN_PASSWORD` | رمز ثابت؛ اگر تنظیم شود، از پنل قابل تغییر نیست |
| `DATA_DIR` | محل ذخیرهٔ داده و تصاویر (پیش‌فرض `./data`) |
| `TRUST_PROXY=1` | وقتی پشت Nginx/Cloudflare هستید (برای محدودیت تلاش ورود بر اساس IP واقعی) |
| `CORS_ORIGIN` | اگر فروشگاه را روی دامنهٔ دیگری میزبانی می‌کنید |

## پنل چه چیزهایی را کنترل می‌کند

- **محصولات:** نام فارسی/انگلیسی، قیمت، قیمت قبل از تخفیف، رنگ‌ها، سایزهای ناموجود، تعداد فروش، توضیحات، تا ۸ تصویر، انتشار/پیش‌نویس
- **مدل‌های لباس** (هودی، دورس، …) و **طرح‌ها و سبک‌ها** (گیمینگ، انیمه، …): افزودن، ویرایش، حذف و تغییر ترتیب
- **رنگ‌ها**
- **متن‌های سایت:** همهٔ متن‌های فروشگاه از هدر تا فوتر، به دو زبان، از جمله سؤالات متداول و کلمات نوار متحرک؛ هر متن را می‌شود به حالت پیش‌فرض برگرداند
- **تنظیمات:** لوگو، فهرست و جدول سایزها، تغییر رمز، دانلود نسخهٔ پشتیبان

تغییرات بلافاصله ذخیره می‌شوند و با باز کردن مجدد صفحهٔ فروشگاه دیده می‌شوند.

## اتصال فروشگاه به API

فروشگاه موقع باز شدن از `/api/public` می‌خواند. اگر فروشگاه را جای دیگری میزبانی می‌کنید:
`<meta name="distort-api" content="https://your-api-domain">` در `public/index.html` اضافه کنید، یا `?api=https://...` را به آدرس بدهید.
اگر API در دسترس نباشد، فروشگاه با داده‌های نمونهٔ داخلی نمایش داده می‌شود.

## امنیت

- رمز با scrypt هش می‌شود؛ ورود بعد از ۵ تلاش ناموفق ۵ دقیقه قفل می‌شود.
- تمام متن‌هایی که مدیر وارد می‌کند هنگام نمایش در فروشگاه escape می‌شوند.
- آپلود فقط PNG/JPG/WEBP/GIF تا ۵ مگابایت را می‌پذیرد و محتوای فایل بررسی می‌شود.
- برای استفادهٔ واقعی حتماً پشت HTTPS (مثلاً Nginx یا Caddy) اجرا کنید.

## هنوز وصل نیست

ثبت‌نام و ورود مشتری، سبد خرید ماندگار، درگاه پرداخت و ثبت سفارش، و ویرایشگر طرح اختصاصی؛ این‌ها هنوز در فروشگاه فقط ظاهر دارند.
